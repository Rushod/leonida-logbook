GTA 6 preload guide for PS5 and Xbox

Updated November 11, 2026

Preloading downloads GTA VI before release day, so you can play the moment it unlocks. The game needs up to 212 GB, so start early.

Preload dates

How you bought itPreload opens
Digital pre-order on PS5November 10, 2026
Boxed copy (download code)November 12, 2026
Game unlocksNovember 19, 2026

Boxed copies of GTA VI contain a download code and no disc, so they need the same download as a digital copy. On Xbox, check the game's page in the store: the Install button appears once pre-install is available for your pre-order.

Before you start

  • Free up 212 GB. See the storage guide for how much room each console has.
  • Use a wired connection if you can. A download this size can take many hours on slow Wi-Fi.
  • Leave room for the day-one update. It is not included in the 212 GB figure.

How to preload on PS5

  • Go to your Game Library and open the Your Collection tab.
  • Select Grand Theft Auto VI.
  • Choose Download. Progress shows under Downloads/Uploads in the control center.

If automatic downloads are switched on and the console is in rest mode with internet access, a pre-ordered game can download by itself once preload opens.

How to preload on Xbox Series X|S

  • Open My games & apps, then Full library, then All owned games.
  • Select Grand Theft Auto VI.
  • Choose Install. Progress shows under Manage, then Queue.

If you have a boxed copy

  • PS5: open the PlayStation Store, choose the More (three dots) menu, then Redeem Code, and enter the code from the box.
  • Xbox: open the Store, choose Redeem, and enter the code.

After the code is redeemed, the game appears in your library and downloads like a digital copy.

Does preloading let you play early?

No. The game stays locked until it unlocks in your region. See what time GTA 6 unlocks.
